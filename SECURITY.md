# Security policy

Please report vulnerabilities privately. Do not open a public issue.

- Use GitHub's "Report a vulnerability" (private security advisory) on this repository, or email the maintainers at the address listed on the project page.
- Include what you found, how to reproduce it, and the version (`gorget-server version`, `gorget version`).
- We acknowledge reports within 3 days, keep you informed, and aim to ship a fix and publish an advisory within 90 days. We credit reporters who want credit.

Supported versions: the latest release. The design and trust model are described in [docs/SECURITY.md](docs/SECURITY.md).
